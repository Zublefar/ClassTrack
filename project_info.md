# Информация о проекте и инструкция для разработчиков/агентов

## 1. Архитектура проекта
* **Frontend (SPA):** Одностраничное приложение на Alpine.js (v3) и Tailwind CSS.
* **Генерация UI:** Главный файл интерфейса **`index.html`** генерируется автоматически с помощью скрипта **`build_html.js`**.
* **Backend (API):** PHP-скрипт **`api.php`** (работа с базой данных MySQL через PDO).
* **Конфигурация:** Подключение к БД и пароли ролей («Учитель», «Родитель») хранятся в **`db_config.php`**.

---

## 2. Зачем используется `build_html.js`?
Файл `index.html` содержит более 1000 строк разметки SPA, шаблонов Alpine.js и логики. Редактировать его напрямую не рекомендуется, так как это может привести к рассинхронизации или ошибкам ручного форматирования. 
Все изменения во вьюхах, компонентах, модальных окнах и JavaScript-логике интерфейса должны производиться в **`build_html.js`**.

---

## 3. Как обновить приложение после изменений
После редактирования `build_html.js` обязательно запустите скрипт генерации в корне проекта:
```bash
node build_html.js
```
Это обновит файл `index.html`.

---

## 4. Авторизация и Роли
* При открытии приложения проверяется кука `school_role` (действует 1 неделю).
* Доступные роли:
  * **`teacher` (Учитель):** Имеет доступ ко всем вкладкам («Расписание ученика», «Сводная матрица», «Справочник учеников», «Справочник кружков») и управлению данными.
  * **`parent` (Родитель):** Имеет доступ только к вкладке «Расписание ученика».
* Пароли ролей настраиваются в `db_config.php`.

# Структура базы данных: `clubs`, `students`, `student_schedules`

Ниже представлено описание таблиц в формате Markdown, включающее типы данных, ограничения и назначение полей.

## clubs — Секции (кружки)
Справочник доступных секций. Определяет название кружка, день недели и время его проведения.

| Поле | Тип | Null | Ключ | По умолчанию | Дополнительно |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **id** | int(11) | НЕТ | PRI | *NULL* | auto_increment |
| **name** | varchar(255) | НЕТ | MUL | *NULL* | |
| **day** | enum('Понедельник','Вторник','Среда','Четверг','Пятница') | НЕТ | MUL | *NULL* | |
| **time** | time | НЕТ | | *NULL* | |
| **deteled** | tinyint(4) | НЕТ | | 0 | |

**Описание полей:**
* `id`: Уникальный идентификатор секции (первичный ключ).
* `name`: Название клуба или секции. Индексировано (`MUL`) для быстрого поиска по названию.
* `day`: День недели, в который проводятся занятия. Ограничен рабочими днями с понедельника по пятницу. Индексировано (`MUL`) для фильтрации расписания по дням.
* `time`: Время начала занятий.
* `deteled`: Флаг мягкого удаления (`0` — активен, `1` — помечен на удаление). Позволяет сохранять историческую целостность данных в расписаниях при удалении кружков из справочника.

Основная таблица со списком учащихся и их балансом.

| Поле | Тип | Null | Ключ | По умолчанию | Дополнительно |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **id** | int(11) | НЕТ | PRI | *NULL* | auto_increment |
| **money** | decimal(7,2) | НЕТ | | *NULL* | |
| **name** | varchar(255) | НЕТ | MUL | *NULL* | |

**Описание полей:**
* `id`: Уникальный идентификатор ученика (первичный ключ).
* `money`: Денежный баланс учащегося. Формат `decimal(7,2)` позволяет хранить суммы до 99999.99.
* `name`: Имя ученика. Индексировано (`MUL`) для ускорения выборок при поиске конкретного ребенка.

## student_schedules — Расписание учеников
Связующая таблица, фиксирующая посещения конкретных секций учениками, а также данные о питании и присутствии.

| Поле | Тип | Null | Ключ | По умолчанию | Дополнительно |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **id** | int(11) | НЕТ | PRI | *NULL* | auto_increment |
| **week_num** | int(11) | НЕТ | | *NULL* | |
| **date** | date | НЕТ | | *NULL* | |
| **student_id** | int(11) | НЕТ | MUL | *NULL* | |
| **day** | enum('Понедельник','Вторник','Среда','Четверг','Пятница') | ДА | | *NULL* | |
| **lunch** | tinyint(1) | ДА | | *NULL* | |
| **snack** | tinyint(1) | ДА | | *NULL* | |
| **departure_time** | time | ДА | | *NULL* | |
| **comment** | text | ДА | | *NULL* | |
| **is_absent** | tinyint(1) | ДА | | *NULL* | |
| **absent_reason** | varchar(255) | ДА | | *NULL* | |
| **clubs** | text | ДА | | *NULL* | |

**Описание полей:**
* `id`: Идентификатор записи в расписании (первичный ключ).
* `week_num`: Порядковый номер учебной недели (например, для разделения четных и нечетных недель).
* `date`: Конкретная дата записи.
* `student_id`: Внешний ключ, ссылающийся на таблицу `students`. Индексирован (`MUL`) для быстрой загрузки истории посещений одного ученика.
* `day`: День недели (дублирует значение из таблицы `clubs` для фиксации факта; допускает `NULL`, если запись создается без привязки к конкретной секции).
* `lunch`: Флаг заказа обеда (`0`/`1` или `NULL`). Используется тип `tinyint(1)` как стандартный булевый флаг в MySQL.
* `snack`: Флаг заказа полдника или перекуса (`0`/`1` или `NULL`).
* `departure_time`: Фактическое время ухода ученика.
* `comment`: Текстовое поле для заметок родителей или преподавателей.
* `is_absent`: Признак отсутствия ученика (`0` — присутствовал, `1` — отсутствовал, `NULL` — статус не определен).
* `absent_reason`: Причина отсутствия (заполняется только если `is_absent = 1`).
* `clubs`: Список выбранных кружков на день (хранится в формате JSON массива строк).

> *Примечание:* Устаревшая таблица `schedules` (хранившая расписание в виде JSON-объектов) больше не используется. Все данные по расписаниям полностью перенесены в реляционную таблицу `student_schedules`.

## logs — Логирование операций и финансов
Таблица для фиксации истории изменений счетов учеников, списаний за полдник и системных событий.

| Поле | Тип | Null | Ключ | По умолчанию | Дополнительно |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **id** | int(11) | НЕТ | PRI | *NULL* | auto_increment |
| **event_datetime** | timestamp | НЕТ | | CURRENT_TIMESTAMP | |
| **event_type** | varchar(50) | НЕТ | | *NULL* | |
| **event_message** | text | НЕТ | | *NULL* | |
| **object_id** | int(11) | ДА | MUL | *NULL* | |
| **user_id** | varchar(50) | ДА | | *NULL* | |
| **error** | tinyint(1) | НЕТ | | 0 | |

**Описание полей:**
* `id`: Уникальный идентификатор записи лога.
* `event_datetime`: Время совершения события.
* `event_type`: Тип события (например, `money`, `students`, `class_schedules`, `login`, `logout`).
* `event_message`: Текстовое описание события.
* `object_id`: Идентификатор связанного объекта (например, `student_id` или `user_id`).
* `user_id`: Идентификатор пользователя (`users.id`), выполнившего действие (заполняется автоматически для всех операций, а также при входе и выходе из системы).
* `error`: Признак ошибки (`0` — успешно, `1` — ошибка).

## users — Пользователи системы и авторизация
Таблица учетных записей пользователей с разграничением ролей.

| Поле | Тип | Null | Ключ | По умолчанию | Дополнительно |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **id** | int(11) | НЕТ | PRI | *NULL* | auto_increment |
| **login** | varchar(255) | НЕТ | UNI | *NULL* | |
| **password_hash** | varchar(255) | НЕТ | | *NULL* | |
| **role** | tinyint(4) | НЕТ | | *NULL* | |
| **student_id** | int(11) | ДА | MUL | *NULL* | |

**Описание полей и ролей:**
* `id`: Уникальный идентификатор пользователя (первичный ключ).
* `login`: Уникальный логин для входа.
* `password_hash`: Хэш пароля (поддерживается проверка стандартных хэшей и обратная совместимость с legacy-паролями).
* `role`: Числовой идентификатор роли:
  * **`0` — Администратор:** Полный доступ ко всем вкладкам и управлению данными.
  * **`1` — Модератор:** Доступ к поиску учеников, настройке их расписания и вкладке «Расписание уроков».
  * **`2` — Родитель:** Доступ только к вкладке «Расписание ученика», автоматически привязан к конкретному ребенку через `student_id`.
* `student_id`: Внешний ключ на таблицу `students` (используется для роли родителя).

## class_schedules — Расписание уроков класса
Справочник расписания учебных занятий и домашних заданий по классам и неделям.

| Поле | Тип | Null | Ключ | По умолчанию | Дополнительно |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **id** | int(10) unsigned | НЕТ | PRI | *NULL* | auto_increment |
| **lesson_number** | tinyint(3) unsigned | НЕТ | | *NULL* | |
| **day_of_week** | enum('Понедельник','Вторник','Среда','Четверг','Пятница') | НЕТ | MUL | *NULL* | |
| **week_number** | tinyint(3) unsigned | НЕТ | | *NULL* | |
| **start_time** | time | НЕТ | | *NULL* | |
| **end_time** | time | НЕТ | | *NULL* | |
| **break_minutes** | tinyint(3) unsigned | НЕТ | | *NULL* | |
| **lesson** | varchar(150) | НЕТ | | *NULL* | |
| **homework** | text | ДА | | *NULL* | |

**Описание полей:**
* `id`: Уникальный идентификатор записи (первичный ключ).
* `lesson_number`: Порядковый номер урока в расписании дня (от 1 до 7).
* `day_of_week`: День недели.
* `week_number`: Номер учебной недели (соответствует выбранной неделе интерфейса).

* `break_minutes`: Длительность перемены после данного урока в минутах.
* `lesson`: Название предмета (заполняется преподавателем).
* `homework`: Домашнее задание.

## Вспомогательные скрипты
* **`write_snack_fees.php`**: Автономный PHP-скрипт для массового/точечного списания средств за полдник. Проверяет таблицу `student_schedules` на наличие `snack = 1` в выбранную дату, уменьшает баланс ученика в таблице `students` и логирует транзакцию в таблицу `logs`.
