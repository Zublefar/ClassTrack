# 🏫 Система управления школьным расписанием и посещаемостью

Веб-приложение (SPA) для комплексного управления расписанием учеников, посещаемостью, кружками, питанием (обеды и полдники), а также расписанием уроков и домашними заданиями с разграничением прав доступа по ролям.

---

## 🚀 Технологический стек

* **Frontend:** 
  * Single Page Application (SPA) на базе **Alpine.js (v3)**
  * **Tailwind CSS** (сборка через Tailwind CLI)
  * Иконки **FontAwesome** (локальные файлы)
* **Backend:** 
  * **PHP** (единая точка входа `api.php`)
  * **MySQL** (через PDO с поддержкой транзакций и реляционных связей)
* **Инструменты сборки:**
  * Node.js-скрипт генерации интерфейса **`build_html.js`**
  * Tailwind CLI (`src/input.css` ➔ `dist/output.css`)

---

## 📋 Основные возможности и модули

1. **Расписание ученика:**
   * Учет посещаемости (`is_absent`, `absent_reason`)
   * Заказ обедов и полдников (`lunch`, `snack`)
   * Фиксация времени ухода (`departure_time`)
   * Выбор кружков и добавление заметок/комментариев
   * Автосохранение изменений по дням с защитой от гонки данных (race conditions)
   * Автоматическая блокировка (blur) прошедших дней для родителей

2. **Расписание уроков класса:**
   * Просмотр сетки уроков по учебным неделям
   * Управление уроками (добавление, удаление с пересчетом звонков и временных интервалов)
   * Добавление и редактирование домашних заданий

3. **Справочник кружков и секций:**
   * Управление списком кружков (дни недели, время)
   * Механизм мягкого удаления (`deteled = 1`) для сохранения целостности исторических записей в расписаниях
   * Аналитика невостребованных секций на текущей неделе

4. **Финансы и логирование:**
   * Учет баланса учеников (`students.money`)
   * Скрипт автоматического/точечного списания средств за полдники (`write_snack_fees.php`)
   * Подробное системное логирование всех операций (`logs`)

5. **Авторизация и ролевая модель:**
   * **Администратор (Роль 0):** Полный доступ ко всем модулям, управлению данными и справочникам.
   * **Модератор (Роль 1):** Доступ к поиску учеников, настройке расписания и расписанию уроков.
   * **Родитель (Роль 2):** Доступ в режиме чтения/просмотра к расписанию своего ребенка и расписанию уроков класса без прав модификации.

## 🗂️ Структура проекта

* **`index.html`** — Главный файл пользовательского интерфейса (генерируется автоматически).
* **`build_html.js`** — Скрипт сборки интерфейса (все правки UI и компонентов выполняются в нем).
* **`api.php`** — REST/AJAX API бэкенд на PHP для работы с базой данных.
* **`db_config.php`** — Конфигурация подключения к MySQL и пароли ролей.
* **`write_snack_fees.php`** — Автономный скрипт списания средств за полдники.
* **`project_info.md`** — Детальная техническая документация и схема базы данных.
* **`project_changes.md`** — История изменений (Changelog) проекта.
* **`src/input.css`** — Исходные стили Tailwind CSS.
* **`dist/output.css`** — Скомпилированный файл стилей.

## ⚙️ Установка и запуск

1. **Клонирование и зависимости:**
   ```bash
   npm install
   ```

2. **Настройка базы данных:**
   * Создайте базу данных MySQL.
   * Настройте параметры подключения в файле **`db_config.php`**.

3. **Сборка стилей и интерфейса:**
   ```bash
   # Сборка стилей Tailwind
   npm run build:css

   # Генерация index.html (при изменении логики в build_html.js)
   node build_html.js
   ```

4. **Запуск:**
   * Разместите проект на локальном PHP-сервере (например, OpenServer, XAMPP, Docker) или запустите встроенный PHP сервер:
     ```bash
     php -S localhost:8000
     ```
